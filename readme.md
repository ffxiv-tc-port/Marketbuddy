# Marketbuddy

[Marketbuddy](https://github.com/PunishXIV/Marketbuddy) 的台服移植版。市場佈告板上架、改價、下架與比價的操作輔助。

🔴 **市場相關的動作一律由你手動觸發**：上架、改價、下架、巡迴、巡檢都要自己按按鈕才會開始，
不會因為遊戲事件或別的插件自己接手；會連續跑的功能（批次上架、全僱員補上架、背包上架到有空位的僱員、這個角色整理一輪、多角色重掛、巡檢自動續跑）預設關閉，
其中多角色重掛與巡檢自動續跑每一輪還要你親手「武裝」，武裝狀態不存檔、跑完一輪自己解除。
跑到一半按 ESC 或面板上的「取消」就停。

## 功能

### 改價與上架
- **調整價格輔助**：點「調整價格」時一併開啟目前市場標價列表與交易履歷；點列表中的一列，就以比它低 1 Gil（或依設定改成百分比）的價格填入並確認，同時把價格複製到剪貼簿。
- **快速鍵**：按住 Ctrl 再點「調整價格」直接沿用剪貼簿的價格；按住 Alt 控制是否連動開啟交易履歷；按住 Shift 可暫時略過部分自動化。
- **出售品視窗的堆疊上限**：上架時自動把數量調成設定的最大堆疊數。
- **快速上架**：按住指定的鍵右鍵點道具，直接進入上架流程（預設未設定按鍵）。
- **壓價尾數捨到倍數**：降價後的價格再無條件捨去到指定 Gil 的倍數（預設關閉）。
- **異常低價保護**：別人少打一個 0 時不跟著降價，那一件維持原價並列進待處理清單（預設開啟，可調金額與倍數門檻）。有 Universalis 成交資料時改拿最新多筆成交排除特殊交易後的共識價來判（過高、過低都算），轉 Gil 用的天價掛單不會再擋住正常價。
- **分身之間不互相跟價**（預設開啟）：板上最便宜的那一筆是你任何一個角色的僱員掛的時候，不去壓它的價。

### 批次上架與補上架（都預設關閉，按了按鈕才開始）
- **批次上架**：出售品視窗旁的面板。勾選背包或這名僱員物品欄裡的道具後按下按鈕，每一疊用與重掛相同的規則逐件查價，再透過遊戲自己的右鍵選單「到市場出售」上架。扣稅後低於 NPC 收購價或低於你設的最低價的不上架（來自背包的改列進「賣給商店」清單，仍要你按那顆按鈕才賣），查不到可用價格的跳過。面板上會顯示這名僱員的市場已佔幾格、其他僱員還有幾格空位；跑完列出「已處理／還要處理」彙整表。
- **預先勾選**（預設開啟）：面板會先把背包裡能上架的道具勾起來，之後才進背包的也一樣；在 InventoryTools 製作清單上的、標成「不自動上架」的、近期查價低於門檻的不勾，你取消過的不會勾回來。只是先勾好，上架仍要你按開始。
- **不自動上架清單**：在面板的道具列上把某種道具標成「不自動上架」，批次上架、全僱員補上架與整理一輪都會跳過它；快速上架與手動上架不受影響。
- **低價道具不重複查價**（預設開啟）：查價低於門檻的道具會記住幾天（可調），期間不再查價；最近因為低價被下架過的道具，快速上架與批次上架也會跳過。開始時按住 Ctrl 可全部重查。
- **全僱員補上架**：僱員選單旁的按鈕。逐一拜訪這個角色的僱員，先重掛已經在賣的，再用那名僱員自己物品欄裡的道具補滿市場空位——只補你在批次上架面板上替他勾過的道具，每一件都先查價。
- **背包上架到有空位的僱員**：僱員選單旁的按鈕。逐名僱員把背包裡勾選的道具上架，一名僱員的市場滿了就換下一名，背包處理完或僱員都走過就收工並列出彙整表；旁邊的「檢視／調整勾選」可以先看會上架哪些。
- **這個角色整理一輪**：僱員選單旁的按鈕，要按兩次確認。逐一拜訪每位僱員：重掛、把這次重掛剛下架回背包的東西交給僱員賣給商店、再用勾選的道具補上架。

### 重掛與下架（出售品視窗與僱員選單旁的面板）
- **批次重掛**：依市場最低價一鍵重新定價眼前這位僱員的商品，或用「全僱員重掛」逐一拜訪所有僱員；可設定只比較 HQ、跳過稅後淨額低於 NPC 收購價的商品。
- **最近成交價定價**（預設關閉）：改用「最近成交價與板上最低價取低者」，成交紀錄只採設定天數內的；遊戲內查價被拒時可改用巡檢資料補位。價格來自 Universalis。
- **查不到行情的商品**：新上架（批次上架、快速上架）時板上沒有別人在賣、最近成交又沒有或太舊，改用資料中心最新多筆成交的共識價先掛上，成交不夠再用其他世界最便宜的一般掛單（預設開啟，可關；之後最低價等規則照舊）；都沒有才留在上限價並列出來，附手動下架按鈕，也會出現在巡檢視窗的「待處理」分頁。
- **批次下架**：「本僱員全下架」與「全僱員下架」，可只下架單價高於門檻的商品、指定某些僱員永遠不下架，下架品收到玩家背包或僱員背包。
- **賣給商店**（預設關閉）：下架後在面板上提供「交給僱員賣給商店」按鈕；兩段式確認，第一下只武裝、倒數內再按一次才賣。另有預設關閉的「併進原有堆疊時也整疊賣掉」。
- **即時掛單面板**（預設關閉）：在遊戲的出售品視窗旁畫一份永遠最新的掛單表，可加上已掛售時間、「這件賣掉過幾次」，以及本世界／資料中心最低價與最近成交（需開啟最近成交價定價才有資料）。看盤欄位顯示扣稅後實拿；按「查日銷」向 Universalis 查詢後，再顯示板上比你便宜的件數、預估幾天賣完與買家常見的一次買量，沒查過的顯示灰色「?」。純顯示，不會因為任何數字自動改價或下架。
- **多角色重掛**（預設關閉，需要 AutoRetainer）：AutoRetainer 處理完一個角色、準備換下一個之前，交由本插件跑一輪全僱員重掛再交還；「武裝一輪」按鈕也放在 AutoRetainer 主視窗的控制列。不在傳喚鈴旁的角色直接跳過；另有預設關閉的選項，在公會工坊裡傳喚鈴就在附近卻搆不到時，請 AutoRetainer 走過去。每個角色要做什麼可以選「只重掛」（預設）或「背包上架＋重掛」：後者每個角色先把背包裡預先勾選選中的道具上架到有空位的僱員，再重掛；低於門檻的只加進賣給商店的清單，不會賣給商店。

### 跨世界價格巡檢（預設關閉，`/mbuddy survey`）
- **掃描**：帶著自己掛售中的清單（預設涵蓋所有角色的僱員，需要 InventoryTools），在每個世界按一次「掃描」，逐件查當地行情並記進 `price_survey.csv`。只送遊戲自己的市場查詢，不改價、不掛售、不下架。
- **比價**：看誰在哪個世界壓你的價。
- **採購**（預設關閉）：巡檢時順便查採購清單上的道具，一件一列、每個世界一欄；純查價，不買。
- **待處理**：逐列給建議價與重新定價按鈕，改價一律要你一列一列按。
- **銷售**：僱員銷售紀錄——比對僱員掛售清單少了什麼，逐列標示信心，可改成一件一列的彙總。
- **換世界**：「去別的世界」按一次換一個世界（透過 Lifestream 的 IPC）；可排除世界（拉姆出廠就排除）。另有預設關閉的「掃完自動換到資料最舊的世界接著掃」，要你親手武裝一輪、有世界數上限。

### 清理背包（設定視窗的「清理背包」頁）
- **背包分揀**：按「分揀背包」把背包裡的東西分成三堆——賣給商店（以前因為低價下架過、最近成交價仍低於你設的最低價）、上市場、要查價。只替你勾好第一堆，勾選的交給「賣給商店」清單後仍要到出售品視窗按兩次確認才賣；不上架、不下架，也不在市場佈告板上查價。在 InventoryTools 製作清單上的道具不會被列進去。
- **常被低價下架的道具**：列出重掛時一再因為低價被下架的道具，可以把勾選的道具 ID 複製成 AutoRetainer 快速出售清單讀得懂的格式（只複製到剪貼簿，不會寫入 AutoRetainer 的設定）。

### 其他
- **這一趟買了多少**：在市場佈告板搜尋結果旁顯示本趟已買的件數與金額，以及最便宜的前幾列能湊到幾件、多少錢（純顯示，不會替你買）。
- **市場資料快取**：重掛時可重用設定秒數內查過的結果，少問伺服器幾次。
- **查價像卡住時自動重送**（預設關閉）。
- **急停**：提供 `Marketbuddy.StopAll` IPC，一次停下正在跑的重掛、上架、下架、賣給商店、巡迴與巡檢；[TCToolbox](https://github.com/ffxiv-tc-port/TCToolbox) 的「全艦隊急停」會呼叫它。只做各功能「取消」按鈕做的事，不關你的視窗、不改設定。
- **塔塔露誇獎**：整輪重掛跑完、巡檢掃完一個世界時，請 TataruPraise 念一句（兩者可分開關）。
- **GilDelta**：在市場佈告板買東西時，告訴 GilDelta 這筆 Gil 花在哪裡。
- **市場診斷**：可選擇把詳細診斷寫進記錄，方便回報問題。

## 指令

- `/mbuddy`：開關設定視窗（分頁：比價視窗／上架／重掛定價／價格防護／全僱員補上架與多角色重掛／下架／清理背包／面板／巡檢與診斷）
- `/mbuddy survey`：開關跨世界價格巡檢視窗

## 台服版的修改

- 介面繁體中文化。
- 新增跨世界價格巡檢（掃描、比價、採購、待處理、銷售、換世界與排除世界）。
- 新增批次上架、全僱員補上架、背包上架到有空位的僱員、這個角色整理一輪（都是手動開始、預設關閉）。
- 新增全僱員重掛／下架巡迴、多角色重掛（搭配 AutoRetainer）、賣給商店、即時掛單面板與看盤欄位、「這一趟買了多少」面板、背包分揀。
- 新增最近成交價定價、異常低價保護、壓價尾數捨到倍數、分身之間不互相跟價；新上架沒有比價資料時改用近期成交共識價或其他世界的一般掛單，都沒有才維持上限價，不再退回最低價。
- 台服查價節流：上一件掛單很多時下一次查詢自動拉長間隔，避開伺服器拒絕。
- 開放唯讀的市場快取查詢 IPC（`Marketbuddy.MarketCache.*`）與急停 IPC（`Marketbuddy.StopAll`）給別的插件；整合塔塔露誇獎與 GilDelta。
- 介面寬度跟著 Dalamud 的字型大小放大；多處降低記憶體用量。

## 安裝

1. 在遊戲內輸入 `/xlsettings` 開啟「Dalamud 設定」，到「試驗性功能」分頁的「第三方插件倉庫」（Custom Plugin Repositories）貼上
   `https://raw.githubusercontent.com/ffxiv-tc-port/DalamudPluginsTC/main/repo.json`
   勾選啟用後按「儲存變更」。
2. 輸入 `/xlplugins` 開啟「插件管理員」（Plugin Installer），搜尋「Marketbuddy」安裝。

請不要安裝上游（國際服）版本，它不是對著台服客戶端做的。

## 需要搭配的插件

- 選用：[AutoRetainer](https://github.com/ffxiv-tc-port/AutoRetainer)（多角色重掛）、[InventoryTools](https://github.com/ffxiv-tc-port/InventoryTools)（巡檢涵蓋所有角色、製作清單上的道具不預先勾選）、[Lifestream](https://github.com/ffxiv-tc-port/Lifestream)（巡檢換世界）、[TataruPraise](https://github.com/ffxiv-tc-port/TataruPraise)、[GilDelta](https://github.com/ffxiv-tc-port/GilDelta)、[TCToolbox](https://github.com/ffxiv-tc-port/TCToolbox)（全艦隊急停）
